# Arquivos Oficiais da Lupa Frontal (ANVISA - Anexo XVII da IN 75/2020)

Se você adicionar aqui os arquivos oficiais da Lupa Frontal (`.svg` ou `.png`), o aplicativo passará a utilizá-los automaticamente no lugar do desenho SVG interno.

Nomes recomendados para correspondência automática por combinação de nutrientes:
- `acucar_adicionado.svg` (ou `.png`)
- `gordura_saturada.svg`
- `sodio.svg`
- `acucar_gordura.svg`
- `acucar_sodio.svg`
- `gordura_sodio.svg`
- `acucar_gordura_sodio.svg`
